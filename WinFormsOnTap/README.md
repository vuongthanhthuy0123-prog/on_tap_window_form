## CẤU TRÚC SOLUTION

| Project | Nội dung |
|---|---|
| `Bai1_TinhCuocDichVu` | Bài 1 – Máy tính tính cước dịch vụ & Giảm giá |
| `Bai2_PhieuSuCoIT` | Bài 2 – Form tiếp nhận & phân loại sự cố IT |
| `Bai3_QuanLyVatTu` | Bài 3 – Quản lý danh mục Vật tư / Linh kiện (ListView) |
| `Bai4_DatChoNgoi` | Bài 4 – Sơ đồ chọn vị trí / Đặt bàn hẹn giờ (Dynamic Controls) |
| `Bai5_QuanLyDonGiaoHang` | Bài 5 – Bảng điều khiển Quản lý Đơn giao hàng (DataGridView, StatusStrip, ErrorProvider) |

**Cách chạy:** Mở `OnTapWindowsForm.sln` bằng Visual Studio 2022 → chuột phải project muốn chạy → **Set as Startup Project** → nhấn **F5**.
